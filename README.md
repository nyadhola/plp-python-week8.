# Personal Mini-Toolkit

## Project Description

The Personal Mini-Toolkit is a Python program that provides three useful tools through a menu. It includes a simple calculator, a to-do list manager, and a number checker.

## Tools Included

* **Simple Calculator:** Performs addition, subtraction, multiplication, and division.
* **To-Do List:** Allows users to add, view, and remove tasks.
* **Number Checker:** Checks whether a whole number is even or odd and whether it is positive, negative, or zero.

## How to Run the Program

1. Install Python 3.
2. Open the project folder in VS Code or a terminal.
3. Run `python toolkit.py`.
4. Select a tool from the menu.
5. Choose option 4 to quit.

## Python Concepts Used

This project uses variables, input and output, conditionals, loops, lists, functions, f-strings, and error handling with `try` and `except`.

## Reflection

The hardest part of this project was organizing the tools so they worked correctly with the main menu. The part that required the most debugging was handling invalid inputs and making sure the program returned to the menu correctly. I tested the calculator with different operations, the to-do list with adding and removing tasks, and the number checker with different numbers. I also tested invalid menu choices and the quit option. This project helped me understand how loops, lists, and conditionals work together in a Python program. I learned that clear messages and comments make a program easier to use and understand. With one more week, I would add a feature to save the to-do list to a file so tasks could be available the next time the program runs.
